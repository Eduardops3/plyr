# QR Shapes Generator

Este plugin para WordPress genera códigos QR en formato SVG usando la librería [chillerlan/php-qrcode](https://github.com/chillerlan/php-qrcode). Permite modificar la forma de los módulos mediante JavaScript.

## Instalación

1. Ejecuta `composer install` dentro de la carpeta del plugin para descargar las dependencias.
2. Copia la carpeta `qr-shapes-generator` dentro del directorio `wp-content/plugins/` de tu instalación de WordPress.
3. Activa el plugin desde el panel de administración de WordPress.

## Uso

Añade el shortcode `[qr_shapes]` en cualquier entrada o página para mostrar el generador de códigos QR. Elige la forma deseada y presiona “Generar QR”.
